# Anatomy Prototype Experiments

This directory contains experimental anatomy-generation workflows and outputs that are not accepted production assets.

## Current Contents

- `skin-pipeline/` - experimental skin-over-bone generation workflow and outputs.
- `skin-trial-20260703/` - earlier skin-over-bone trials, including the accepted Style E hand reference.
- `surface-illustration-trials/` - simplified competitor-style surface and skeleton-transparent trials.
- `who-standard-bases-20260612/` - WHO-derived standard base candidates, source crops, cleaned bases, and calibration files.

## Handling Rules

- Move reviewed usable outputs to `../../production/`.
- Move reusable source anatomy material to `../../anatomy-sources/`.
- Keep failed, unstable, or exploratory runs here.
- Archive old POC batches under `../../archive/`.
- Do not treat any file here as app-ready.
