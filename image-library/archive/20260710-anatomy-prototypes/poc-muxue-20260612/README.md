# 木穴製圖 PoC

使用《WHO Standard Acupuncture Point Locations in the Western Pacific
Region》(2008) 第 164 頁 PC8 掌面向量圖作為底圖，清除原有文字、PC8
穴位點、粉紅肌腱及引導線後，重製木穴（11.17）標註。

`木穴_C版_WHO掌面線稿.*` 為已淘汰的初版，PIP–MCP 錨點向下錯置一個
指節，不可作定位用途。正式評估請使用：

- `木穴_正式評估版_WHO掌面線稿.svg`
- `木穴_正式評估版_WHO掌面線稿.png`

`v2` 修正放大圖取景：降低倍率，使食指近節上下橫紋、兩側皮緣及相鄰
節段完整落在放大圈內。

`v3` 不再採用骨性 PIP／MCP 推測。上下指節邊界及 C／D／E 線均直接由
使用者在 `v2` PNG 上的藍色、青色標記擬合，穴點為 D 線在兩條標記邊界
之間的 `1/3`、`2/3`。

`v4` 精簡文字：移除上下穴名稱、邊界名稱、三分點比例補充、校準說明框及
圖例；手別修正為左手掌面。

## 重建

```bash
python3.12 prepare_who_palm_base.py
python3.12 build_muxue_formal.py
qlmanage -t -s 2800 -o . 木穴_精簡評估版_v4_WHO左手掌面線稿.svg
```

## 定位

- 掌面食指第一節 D 線。
- 中央線向中指側外開二分。
- 近端指節橫紋至掌指橫紋採三分點法，取 `1/3`、`2/3` 兩點。
- 臨床常只取下穴；本圖保留兩穴以呈現原始定位法。

正式版校準依據：

- 原書照片兩個黑點中心約為 `(300.30, 370.26)`、`(308.21, 407.57)`。
- 依 `1/3`、`2/3` 反推節段邊界約為 `(292.39, 332.95)` 至
  `(316.12, 444.88)`。
- WHO 圖食指近節使用 PIP `(356.0, 465.5)` 至 MCP `(363.5, 491.0)`。
- D 線偏移量按 WHO 圖該節局部指寬的 `2/10` 計算，不使用固定畫布像素。
