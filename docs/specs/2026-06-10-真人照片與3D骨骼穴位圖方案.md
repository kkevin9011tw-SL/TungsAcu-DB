# 真人照片與 3D 骨骼穴位圖方案

**日期**：2026-06-10  
**狀態**：延後執行，尚未定稿  
**目的**：建立可重複使用的高品質穴位圖製作流程，取代比例失真、解剖品質不足的純向量手繪原型。

## 決策摘要

優先測試「真人照片底圖 + 3D 骨骼配準 + Affinity 標註」。

不再以簡化向量輪廓直接模擬人體解剖，也不以兩張不同姿勢的 2D 手部圖與骨骼圖直接疊合。2D 圖硬疊通常會因手指姿勢、透視與比例不同而錯位。

## 建議流程

1. 拍攝標準化真人照片：
   - 手背或手掌垂直鏡頭。
   - 固定相機高度、焦段、燈光與背景。
   - 畫面放置比例尺。
   - 左右手、不同身體部位分別建立母版。
2. 在 Blender 載入可合法修改的開源 3D 骨骼模型。
3. 以照片作相機背景，使用正交相機配準：
   - 先對準腕關節及掌骨。
   - 再調整 MCP、PIP、DIP 關節和各節指骨。
   - 關節中心與骨軸一致比外輪廓完全貼合更重要。
4. 以相同相機輸出透明背景骨骼 PNG。
5. 在 Affinity 疊合並排版：
   - 真人照片置底。
   - 骨骼層透明度先測試 15–30%。
   - 視需要使用遮罩、Normal、Multiply 或 Soft Light。
   - 穴位點、名稱、引導線、等分線及寸法各自獨立圖層。
6. 確認單張測試圖品質後，再建立可批次複用的部位母版。

## 建議圖層

```text
文字與穴名
穴位點
尺寸與等分線
表面解剖線
骨骼透視
真人照片
背景
```

## 第一張測試

以「指駟馬穴」作為概念驗證：

- 一張自行拍攝、清晰且垂直的手背照片。
- 僅配準手骨及食指指骨。
- 標示指駟馬一、二、三穴。
- 標示中央線、指間關節線、二分與三分定位。
- 同時比較「保留真人質感」與「柔和醫學插畫處理」兩種版本。

## 素材與授權

候選素材：

- Z-Anatomy：Blender 人體解剖模型。
- NIH 3D：手及腕骨模型。
- DBCLS / Wikimedia Commons：固定視角骨骼圖，可供快速原型參考。

正式採用前必須逐項確認授權、作者標示及公開網站使用條件。真人照片優先自行拍攝，避免肖像權與來源不明問題。

## 不建議

- 不使用 AI 生圖決定骨骼、關節或穴位位置。
- 不直接描摹參考網站的受著作權保護插畫。
- 不以不同姿勢的真人照片和 2D 骨骼圖強行疊合。
- 未完成單張品質驗證前，不批量製作全部穴位。

## 未來啟動條件

1. 使用者提供或拍攝標準手部照片。
2. 選定可使用的 3D 手骨模型及授權。
3. 確認左右手、圖像風格和穴位定位文字。
4. 完成一張指駟馬測試圖並人工確認品質。
