# 一一、二二、三三部位穴位標定第一輪

生成日期：2026-06-14

## 範圍

- 一一部位：27 穴，25 張合併／單穴圖。
- 二二部位：11 穴，7 張合併／單穴圖。
- 三三部位：15 穴，6 張合併圖。
- 特殊試作：三叉一、三叉二、三叉三握拳視角，1 張。
- 三個正式部位共 53 穴，已全部覆蓋。

## 狀態

- `approved_existing`：5 張，沿用先前已核可版本。
- `review_ready`：7 張，標準伸直手指正視圖，可先檢查定位線與分點。
- `needs_anatomy_review`：27 張，涉及側視、握拳、立掌、屈肘、黑白肉際、
  掌骨間隙或貼筋貼骨橫向位置。

「第一輪可審核」不等於正式核可；只有 `approved_existing` 才是既有核可圖。

## 建議檢查順序

1. `一一部位_第一輪總覽.png`
2. 一一部位標為「第一輪可審核」的 7 張：
   大間／小間、浮間／外間、中間、脾腫、眼黃、肺心、二角明。
3. 一一部位側線與拇指圖：
   還巢、指腎、指三重、心膝、指五金／指千金、指駟馬、婦科、
   制汙、止涎、五虎、膽。
4. `二二部位_第一輪總覽.png`：逐張校正掌骨間隙與特殊手勢。
5. `三三部位_第一輪總覽.png`：寸位先看縱向比例，再校正貼骨橫向位置。
6. `特殊視角_第一輪總覽.png`：三叉三以原書握拳照片為姿勢基準。

## 三叉三

WHO 書中沒有真正的握拳手背正視骨骼圖。WHO 僅在文字中提到握拳取穴，
並有開掌或局部掌面示意，不能直接當成三叉三底圖。

第一輪因此保留《董氏奇穴穴位詮釋解》圖 13-2 的握拳姿勢，標出三個指縫
接合處。三叉三正式版仍需確認「緊貼第四指、筋下骨旁」的精確位置。
