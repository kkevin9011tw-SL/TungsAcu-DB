# Marked Figures

用「穴位標記工具」(`marker-tool/穴位標記工具.html`)人工標定後輸出的成果放在這裡。

## 檔案

每個穴位(或同圖數穴)一組,命名為 `穴號_穴名.副檔名`:

- `11.21_三眼穴.json` — 標記資料(座標、定位線、放大鏡、比例尺、寸投影等;含 `points` 索引欄)
- `11.21_三眼穴.png` — 成圖(固定像素,可直接當正式圖)
- `11.21_三眼穴.svg` — 向量成圖(可再編輯)

JSON 為**人工標記真值**,座標以底圖 viewBox 單位儲存,供後續 Python 製圖引擎使用。

## 怎麼把下載存到這裡

網頁下載一律走瀏覽器的下載資料夾,無法由網頁指定路徑。請二擇一:

1. 把瀏覽器的「下載位置」設成本資料夾(一次設定,之後自動);或
2. 開啟瀏覽器「每次下載前詢問儲存位置」,下載時手動選這裡。
