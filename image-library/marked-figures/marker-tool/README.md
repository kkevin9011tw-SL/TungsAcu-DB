# 穴位標記工具

人工標定穴位定位圖的單頁工具。**人工標記為真值,程式只做幾何**;輸出供後續 Python 製圖引擎使用。

## 檔案
- `穴位標記工具.html` — 工具本體(雙擊即可開)
- `acupoints-data.js` — 部位/穴位下拉資料(由 `data/穴位表.csv` 自動產生,勿手改)
- `bases-data.js` — 19 張標準底圖內嵌資料(由 `who-standard-bases-20260612/clean-bases/` 產生,勿手改)

三個檔要放在同一資料夾。

## 開啟與存檔
1. **雙擊 `穴位標記工具.html`** 用瀏覽器開。
2. 下載的檔案會進**瀏覽器的下載資料夾**。要讓它落在 `TungsAcu-DB/image-library/marked-figures/`,把瀏覽器的下載位置設成該資料夾即可(一次設定):
   - Chrome:設定 → 下載內容 → 位置 → 變更
   - Safari:設定 → 一般 → 檔案下載位置 → 其他…
   - 絕對路徑:`/Users/samue11in/Projects/TungsAcu-DB/image-library/marked-figures`

## 操作
1. 從「選底圖」下拉直接選對應底圖(19 張標準底圖內建;特殊底圖才用「載入其他 SVG…」)
2. 選部位 → 選穴位
3. 選工具標記(見下表)
4. 「選取」工具可移動/縮放元素;屬性面板調線粗、點大小、字級、顏色、文字
5. 下載 JSON / SVG 圖 / PNG 圖

### 工具
| 工具 | 用途 |
|------|------|
| 選取／移動 | 預設;點選元素拖移、拖白色端點縮放 |
| A–E 線 | 指節定位線(藍虛);可選 A–E,另有「依 A、E 補 B C D」 |
| 穴位紅點 | 實心紅點,標目前選的穴位(需先選穴位) |
| 空心紅點 | 紅色空心圈,標相鄰參考穴(免選穴位) |
| 界線(紅虛) | 指節/關節上下界 |
| 投影線(綠虛) | 把穴位平行投影對到比例尺 |
| 比例尺 | 設等分、頭值/尾值;**「標示寸數」可在任意刻度旁標數字、且可標多個**(如 `1,3`) |
| 寸投影 | 從紅點拉虛線到比例尺對應寸數並標數字(需先有比例尺) |
| 放大鏡 | 圈一區放大進圓,自動帶入底圖與標記 + 外切連接線;放大圓與來源圈可各自獨立拖移(1–3 指預設放拇指側、4–5 指放尺側,自動避開原圖) |
| 引線標註 | 文字 + 指引線(標肱骨外上髁、肘橫紋等) |
| 文字 | 自由文字 |

### 編輯
- **返回**:`↶ 返回` 鈕 / `Cmd+Z`(`Cmd+Shift+Z` 重做);涵蓋建立、移動、縮放、刪除、改屬性等所有動作(可回 80 步)
- **複製 / 貼上**:選一個元素 → `複製` 鈕或 `Cmd+C` → `貼上` 鈕或 `Cmd+V`,產生位置稍偏移的副本並自動選中(連續放同類元素好用)
- 在輸入框內打字時,`Cmd+C/V/Z` 維持系統原生行為

- 顏色:工具區色票(紅/藍/綠/粉/黑),新畫元素套用;選取後屬性面板也可改色
- 操作:雙指滑動平移、雙指捏合縮放;`V` 選取、`Esc` 取消、`Del` 刪除
- 輸出畫布自動涵蓋所有標記(放大圓放圖外也不會被切)
- 檔名自動為 `穴號_穴名`(如 `11.21_三眼穴`,以實心紅點為準),對得上 CSV 穴號

## 輸出
存到 `TungsAcu-DB/image-library/marked-figures/`:`穴號_穴名.json`(標記真值)、`.png`(成圖)、`.svg`(向量成圖)。
JSON 含 `points` 索引欄與所有標記座標(底圖 viewBox 單位)。
